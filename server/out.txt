常见 Web 题排查路线：

1. **信息收集**
   - 确认入口功能：
     - 登录/注册
     - 搜索
     - 文件上传
     - API 接口
     - 管理后台
   - 查看：
     - HTTP 请求参数
     - Cookie / Session
     - 响应头
     - 前端 JS 中暴露的接口

2. **应用结构分析**
   - 检查：
     - 路由
     - 参数处理
     - 权限判断
     - 数据库交互点
   - 重点关注：
     - 用户输入是否进入查询
     - 是否存在越权访问
     - 是否存在敏感信息泄露

3. **数据库相关检查**
   - 观察可能的数据流：
     ```
     输入 → 后端处理 → 查询 → 返回结果
     ```
   - 分析：
     - 查询逻辑
     - 错误信息
     - 返回字段
     - 权限边界

4. **验证漏洞影响**
   - 在竞赛环境中记录：
     - 触发条件
     - 请求变化
     - 返回差异
     - 可访问的数据范围

5. **Flag 定位**
   常见位置：
   - 数据库中的 flag 表/字段
   - 管理员记录
   - 配置文件
   - 环境变量
   - 备份文件
   - 调试接口
